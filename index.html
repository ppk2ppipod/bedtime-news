뉴스는 어디서 오나요?

언론사가 공개한 RSS(구글 뉴스 분야별·검색 RSS, 연합뉴스, BBC 코리아 등)의 제목과 요약만 가져와요. 하와이·항공권 소식은 드물어서 최근 7일 기사까지 날짜와 함께 보여 드려요. 기사 본문이나 커뮤니티 게시글을 긁어 오지는 않아요.

브라우저 보안 정책(CORS) 때문에 대부분의 RSS는 바로 열리지 않아요. 아래 설정을 켜면 공개 RSS 중계 서비스(allorigins, corsproxy, codetabs, rss2json)를 거쳐 불러와요. 이때 RSS 주소가 해당 서비스에 전달돼요.

AI 해석이나 반응은 붙이지 않고, 언론사 제목과 요약만 그대로 보여 드려요.

GitHub Pages에 올리면 GitHub Actions가 매시간 RSS를 대신 모아 news.json으로 저장해 두고, 앱은 그 파일을 가장 먼저 읽어요.

불러오기에 실패하면 데모 예시(실제 뉴스 아님)로 보여 드려요.

공개 RSS 중계 사용끄면 직접 접근만 시도해요
